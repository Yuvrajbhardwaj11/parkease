# ParkEase Client

Landing page for the ParkEase smart parking platform.

## Run locally

```bash
cd client
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

The Vite dev server proxies `/api` requests to the backend at `http://localhost:5000`.

## Backend

From the `server` folder:

```bash
npm run dev
```
